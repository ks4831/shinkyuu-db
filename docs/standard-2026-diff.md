## 1. 調査概要

### 1.1 目的
第35回国家試験から適用される **2026年版出題基準** を公式資料から精査し、現在DBが分析対象にしている **第29〜34回（2020年版出題基準の実績）** との差分を明確化する。
「過去6年の頻出（pastFrequency）」と「第35回からの新基準重要度（newStandardPriority）」を混同せず、第35回受験生向けの学習優先順位を設計できる状態にする。

### 1.2 結論サマリ（FACT）
- **適用開始**：2027年（令和9年）2月の**第35回**国家試験から。〔A〕
- **改訂回次**：2002年初版以来 **4回目**の改訂（前回は2020年版＝第3回改訂、第29回から適用）。〔A〕
- **はり師・きゅう師の試験科目は14科目のまま変更なし**（医療概論／衛生学・公衆衛生学／関係法規／解剖学／生理学／病理学概論／臨床医学総論／臨床医学各論／リハビリテーション医学／東洋医学概論／経絡経穴概論／はり理論／きゅう理論／東洋医学臨床論）。〔A〕
- 大項目・中項目・小項目の**3層構造は前回と同一**。URL・科目IDに影響する構造変更なし。〔A〕
- **最大の構造変更は「東洋医学臨床論」**：2020年版で症候・疾患を頻度別（よく遭遇する／遭遇することがある／知っておく）に列記していたところ、**疾患名を全面的に割愛し「症候」中心に再構成**。さらに **EBM（根拠に基づいた鍼灸治療）・研究倫理・緩和ケア・災害医療・産業/学校/母子/高齢者保健における鍼灸** の大項目を新設。〔A〕
- **経穴数の「157→180穴」拡充は "あん摩マッサージ指圧師" の東洋医学概論・経絡経穴概論に限った変更**であり、はり師・きゅう師の経絡経穴概論（従来から全正経＋督任脈を対象）には直接は及ばない。〔A〕以前の調査メモにあった「臨床上重要な経穴の拡充」は **あはき（あん摩）向けの記述** であることを確認。
- **きゅう理論に「TRPチャネル」が明示追加**（灸刺激の受容と伝導）。〔A〕
- **リハビリテーション医学に「内部障害のリハビリテーション」大項目を新設**（呼吸器・循環器・腎/内分泌疾患の評価・リスク管理・運動療法・生活指導）。〔A〕
- **東洋医学概論に「日本伝統医学」大項目を新設**（日本伝統医学の歴史／中医学との違い）。〔A〕
- **臨床医学各論に「女性疾患」「高齢者に多い疾患」大項目を新設**、感染症に **COVID-19** を明記。〔A〕

## 3. 2020 → 2026 変更概要（報告書「主な改正事項」＝全文 FACT / 信頼度 A）

出題基準検討委員会報告書 II が挙げる改正事項は次の6点：

1. **専門基礎分野の出題基準を統一**：カリキュラム（学校養成施設認定規則の専門基礎分野の教育内容・単位数）が「あん摩マッサージ指圧師」と「はり師及びきゅう師」で同一であることから、専門基礎分野（解剖・生理・病理・総論・各論・リハ・衛生・関係法規・医療概論）の出題基準を**両資格で一本化**した。
   - → **当DBへの影響：小**。当DBは元々はり/きゅう視点で専門基礎を扱っており、科目構成は不変。
2. **東洋医学臨床論：疾患名を割愛**。2020年版は遭遇疾患・症候を頻度別（よく遭遇する／遭遇することがある／知っておく）に列記していたが、**今回、疾患名を削除し症候ベースに整理**。理由：①疾患名は臨床医学各論に記載済み、②あはき臨床は「症候から病態を捉えて治療する」。
3. **（あん摩マッサージ指圧師の）東洋医学概論・経絡経穴概論の経穴：157穴 → 180穴**。①正経十二経脈の始終経穴、②解剖学的に重要な経穴、③臨床的に重要と考えられる経穴 の計 **24穴を追加**、重要度が低い **1穴を削除**。さらに **奇穴4穴を追加**（計184穴）。巻末に「あん摩マッサージ指圧師 経穴（180穴）・奇穴（4穴）一覧」を新設。
   - → **重要な限定**：この経穴拡充は **あん摩マッサージ指圧師の科目に対する記述**。はり師・きゅう師の経絡経穴概論は従来どおり全正経＋督任脈（実務上361穴）＋要穴・奇穴・新穴を対象とし、**「穴数の拡大」という形の変更はない**。
4. **項目の追加・削除**：専門基礎分野・専門分野で「2020年改訂以後に新たに重要性が増した項目」を追加（§5〜§9 で科目別に詳述）。
5. **記載方法**：3層構造は前回同様。索引を専門基礎（共通）＋専門（あん摩）＋専門（はり・きゅう）で一本化。
6. **略語集を新規作成**（巻末）。

**適用**（報告書 III）：2027年（令和9年）2月の第35回国家試験から。〔A〕

```ts
  status: 'unchanged'|'expanded'|'new'|'reduced'
  tier: 'S'|'A'|'B'|'C'   // 新基準での学習優先度（人手評価）
  evidence: 'A'|'B'|'C'
  note?: string
}
```
- 既存の `importance` は当面 `pastFrequency.tier` のエイリアスとして温存（後方互換）。
- 表示は「過去6年：18問（★★★★★）／第35回新基準：拡充（★★★）」のように**2軸を並記**。

### 12.2 バッジ（§14）
`newStandardPriority.status` に応じて（未実装・文言案のみ）：
- `new` → **「2026年版で新設」**
- `expanded` → **「2026年版で拡充」**
- `reduced` → **「2026年版で整理」**
- `unchanged` かつ `pastFrequency.tier==='S'` → **「6年連続の頻出」**（既存の頻出表示を流用）
バッジは「公式の新基準」と「当サイトの分析」を視覚的に分ける。予測（PREDICTION）にはバッジを付けない。

### 12.3 段階的な実装ロードマップ（提案）
1. **Ver.7.7（データ）**：`themes[]` に §8.2 の studyPoint/aliases 追記（テーマ数は増やさない）。docs更新。
2. **Ver.7.8（テーマ）**：§8.1 の T1〜T5 を **最小限**新設（5テーマ程度）。`newStandardPriority` フィールド導入。`blueprintVersion` は CSV=2020 のまま（1,080問は2020年版実績なので不変）。

### 12.4 やらないこと（重要）
